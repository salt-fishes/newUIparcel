## 最终交付目标（一句话）

**将 newUIparcel 的界面与功能全量对齐 Web 参考版（--main），并补齐适合 Android 后台运行的 AI 自动解析：只处理启用后的新消息、跨来源幂等去重、自动地址归类、可控重试和密钥保护，同时保留短信读取、通知监听、5 种桌面小组件、MIUI 适配与真实身份码跳转。**

## 已锁定决策（执行约束）

1. **无玻璃效果**：面板/卡片/芯片为各主题不透明纯色 + 主题 outline 细边框；主题对角渐变背景保留。
2. 录入短信保持全屏路由页（非 Dialog）。
3. AI 网络层用 HttpURLConnection + kotlinx-serialization，零新第三方依赖。
4. **仅 https**：不加 usesCleartextTraffic；http 地址 UI 层拒绝并提示。
5. AI 自动解析由用户显式启用，支持正则独占、AI 优先和 AI 独占；只调度启用时间后的新消息，旧短信不自动回灌。
6. 主题 = 4 套 + 跟随系统（第 5 项）。
7. 身份码仅做真实 Scheme 跳转，不做 Web 版演示假码。
8. 每轮不做构建；构建验证由用户统一执行并反馈。
9. 安装包只保留 `arm64-v8a` ABI，不生成 universal APK；是否提供 AAB 以后再定。
